お問い合わせ

OpenDots Home AI は個人が運営しています。プライバシーやデータの取り扱いに関するご質問、データ削除・アクセス権の取り消しのご依頼は、次の方法でご連絡ください。

GitHub の Issue

本サイトのリポジトリの Issue からご連絡いただけます。

Issue を作成する

Issue は誰でも読める公開の場所です。パスワード・トークン・認証コード・個人情報・Google Drive の内容・削除してほしいデータの詳細は、絶対に書き込まないでください。 データの削除などのご依頼は、Issue には「連絡を希望します」とだけ書いてください。運営者が、公開されない方法をご案内します。
