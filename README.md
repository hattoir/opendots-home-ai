# opendots-home-ai

OpenDots Home AI の公式紹介ページ・プライバシーポリシー・利用規約を公開するための**静的サイト専用リポジトリ**です（GitHub Pages）。

- 含まれるもの: HTML / CSS / SVG のみ
- 含まれないもの: OpenDots 本体のソースコード、サーバー情報、OAuth 認証情報、Knowledge Vault の内容
- ビルド工程なし。ルート直下をそのまま公開します（`.nojekyll`）

| ページ | ファイル |
| --- | --- |
| ホーム | `index.html` |
| プライバシーポリシー | `privacy.html` |
| 利用規約 | `terms.html` |
| お問い合わせ | `contact.html` |

ここに秘密情報（トークン、鍵、`.env`、内部URL）を置かないでください。
